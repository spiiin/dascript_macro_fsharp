# Общий Source-протокол

Необязательная перегрузка `ce_source(builder, input)` преобразует внешний
источник в форму, которую уже понимают операции builder. Она определяется
в обычном отдельном модуле; менять `computation.das` не требуется.

```das
require ./lib/computation_macro.das
require ./support/game_source_builder.das

let result=computation(GameSourceBuilder(minimumHealth=10)) {
    let health=HealthCheck(health=25) |> bind
    for(target in TargetRange(first=100,count=3)) {
        print("Target {target}, health {health}\n")
    }
    return health
}
```

В `game_source_builder.das` HealthCheck превращается в Result<int>, а TargetRange
в native range. Все остальные операции GameSourceBuilder делегирует Result.
Пример запуска — `source_demo.das`.

## Где применяется

- `let/var x = source |> bind` и `source |> bind`;
- каждый исходный лист `and_bind`, до MergeSources/Bind2/Bind2Return;
- каждый источник одиночного и одновременного `for`;
- `return source |> return_from` и `source |> yield_from`;
- соответствующие разрешённые формы Sequence и сохранённых вычислений.

Обычные `return value`, `yield value`, условия While и `use_resource` не
проходят через Source. Поддержка Source не добавляет Sequence маркер and_bind.

Преобразование однократное, не рекурсивное: результат ce_source не передаётся
повторно в ce_source. Промежуточные пары MergeSources тоже не преобразуются.
Тип аргумента Bind/For выводится из преобразованного источника. Оптимизации
BindReturn/Bind2Return и hooks циклов получают уже этот тип.

## Время выполнения

Выражение источника и его преобразование выполняются один раз при достижении
шага. Проверка наличия перегрузки и вывод типа ничего не исполняют. Error/None
пропускает последующие шаги; and_bind сохраняет собственную семантику группы
и вычисление её источников слева направо. Hook zip может отказаться от обхода,
тогда и преобразования источников не запускаются.

Для Sequence преобразование происходит при чтении, а не создании итератора.
Для deferred оно повторяется при каждом запуске; deferred Sequence выполняет
его при чтении соответствующего нового итератора.

## Значения и владение

Если перегрузки нет, type-only marker `CeSourceFallback` удаляется из AST:
используется исходное выражение, без runtime identity-функции и без копирования
массива или итератора. Ссылки и const-квалификаторы сохраняются.

Созданные адаптером временные коллекции удерживаются на время bind/for и
освобождаются также при исключении. Заимствованные переменные остаются у
владельца. Для return_from/yield_from сохраняется контракт соответствующей
операции builder. Iterator-результаты Sequence проходят существующую защиту
закрытия вложенных источников.

Пользовательский адаптер отвечает за корректность собственного владения:
нельзя возвращать ссылку на локальные данные или на временный входной объект,
который не будет жить до окончания обхода. Предпочтительны копируемые описания
источника, как HealthCheck/TargetRange/Batch, или источники с явным владельцем.
Исключения внутри самого адаптера не превращаются автоматически в Error/None.

`ce_source` должен возвращать источник: void отвергается диагностикой
`ce_source must return a source, not void`.

## Проверки

`test_source_protocol.das` проверяет число вызовов фабрик и преобразований,
порядок and_bind, остановку после None, For/zip, передачу результата,
коллекции и освобождение heap при ошибке, ссылки с адаптером и без него, Sequence и
повторные deferred-запуски. `test_source_void.das` — отрицательный тест.
Запуск: `../run.ps1 -Test`.
