# Диагностика CE

Неподдерживаемый and_bind выдаёт целевую ошибку с реальным исходным местом
компилятора, а не только строкой пути внутри сообщения:

```text
error[31403]: computation: and_bind is unsupported for builder ...;
define ce_merge_sources(builder, left, right) or use sequential bind
tests/test_and_bind_unsupported.das:6:75
    let value = computation(...) { ... |> and_bind(...) |> bind; ... }
                                             ^^^^^^^^
```

Проверяется отсутствие операции и неподходящее сочетание источников, например
Result с Option. Для этих двух случаев должна быть ровно одна ошибка, без
каскада из typedecl и сгенерированных блоков.

Макрос сохраняет LineInfo marker в compile-time метаданных. При неподдерживаемом
merge он подставляет заведомо неуспешный static_assert с этой позицией и
типизированным продолжением, чтобы не порождать вторичные ошибки вывода типов.
Такой код не может успешно скомпилироваться и выполниться. Успешные источники
и merge не вычисляются дополнительно.

Owned return без перемещения сообщает на пользовательской строке:

```text
owned CE: value must be moved; use 'return <- value'
tests/test_move_copy.das:7:8
```

Другие ошибки пользовательских типов могут сопровождаться дополнительной
диагностикой компилятора; библиотека не переоформляет все ошибки daScript.

test_diagnostics.ps1 проверяет exit code, текст, самостоятельную строку позиции
компилятора, отсутствие внутренних исключений и каскада для and_bind. Проверка
входит в полный run_computation.ps1 -Test.
