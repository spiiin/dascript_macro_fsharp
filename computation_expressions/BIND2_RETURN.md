# Bind2Return

Быстрый путь для соседних `and_bind |> bind` и завершающего обычного return:

```das
let result = computation(ResultBuilder()) {
    let pair = result_ok("Mage") |> and_bind(result_ok(12)) |> bind
    return "{pair.first}, level {pair.second}"
}
```

Синтаксис не меняется. Вместо `MergeSources → BindReturn` макрос может вызвать
`ce_bind2_return(builder, left, right, mapper)` напрямую. Специализированные
перегрузки добавлены для Result, Option, Validation и List.
Пример: `bind2_return_demo.das`.

## Контракт

```text
ce_bind2_return(builder, left : M<A>, right : M<B>,
                mapper : block<(pair:tuple<first:A;second:B>):U>) : M<U>
```

`M<T>` — условное обозначение контейнера. В нашем протоколе mapper принимает
одну пару с полями first/second, сохраняя существующую форму переменной bind.
Это не буквальная сигнатура builder-метода F#.

Операция должна быть эквивалентна `ce_merge_sources` с последующим BindReturn:
совпадают результат и его тип, порядок эффектов, ошибки, вызовы mapper.
Входные источники к моменту вызова уже вычислены слева направо ровно один раз.
Error/None/invalid/пустой список не отменяют вычисление правого источника;
native panic прерывает группу сразу.

Как и BindReturn, операция необязательна. Общая перегрузка возвращает типовой
маркер `CeBindReturnFallback`; она не выполняется во время CE. Если подходящей
перегрузки нет, макрос пробует Bind2 с обычным продолжением, затем прежний MergeSources с BindReturn или Bind/Return. См. [Bind2](BIND2.md).
Регистрация имени builder и изменение ядра для сторонней перегрузки не нужны.
Для вывода типа пары прежние `ce_merge_sources` и `ce_unwrap` по-прежнему нужны.

Применяются прежние ограничения BindReturn: return должен непосредственно
следовать за bind и завершать scope. Промежуточная инструкция, return_from
или явный move/ref-return отключают Bind2Return, но могут использовать Bind2. Bind без переменной поддержан.

Для цепочки из трёх и более источников оптимизируется внешнее объединение
перед return; вложенные группы пока используют обычный MergeSources.
Форма вложенных пар не меняется. Sequence не затронут.

## Реализации

- Result возвращает первую ошибку слева направо и не вызывает mapper при Error.
- Option возвращает None при отсутствии любого значения.
- Validation накапливает обе группы ошибок в том же порядке, сохраняя count.
- List сразу заполняет итоговый массив декартова произведения, без отдельного
  массива всех пар; внешний цикл соответствует левому источнику.

В Value-реализациях сохраняется точный тип обычного Return, в том числе
const-квалификаторы вложенных tuple. Это проверяется сравнением типов
быстрого и обычного пути.

## List: снимки и память

Старое раскрытие сначала материализовало все пары, затем запускало mapper.
Чтобы сохранить эти значения при изменении исходных массивов внутри mapper,
быстрый путь сначала копирует элементы каждого источника в отдельный снимок.
Копирование поверхностное, как при старом построении пар: указатели внутри
элементов не превращаются в глубокие копии.

Вспомогательная память составляет O(N+M), вместо O(N*M) пар. Итоговый массив
в обоих случаях содержит N*M результатов. Если один источник пуст, снимки
не создаются и mapper не вызывается. Фиксированные и динамические массивы,
включая смешанные пары, поддержаны; элементы должны быть копируемыми.

Обычные заимствованные источники не перемещаются и не очищаются макросом.
Если mapper сам меняет их, эти изменения остаются видимы пользователю, но
набор пар текущего вычисления сохраняется. Временные источники, снимки и
частичный результат освобождаются и при исключении в mapper.

В проверке двух массивов по 64 int heap перед первым вызовом mapper составил
1024 байта для быстрого пути и 33280 байт для обычного. Это измерение занятой
heap-памяти в указанной точке, не времени выполнения или общего пика памяти.

## Проверки

`run_computation.ps1 -Test` включает:

- `test_bind2_return_dispatch.das`: фактический вызов Bind2Return без MergeSources,
  порядок и однократность источников, промежуточные действия, цепочка из трёх
  источников, bind без переменной и fallback внешнего builder;
- `test_bind2_return.das`: Error/None/invalid, порядок ошибок, отсутствие вызовов
  mapper при неуспехе, совпадение значений и типов со старым раскрытием;
- `test_bind2_return_list.das`: декартовы результаты, снимки при изменении
  источников, сравнение памяти, повторные исключения без роста heap и cleanup;
- прежние тесты and_bind, BindReturn, владения массивами, вложенных групп,
  состояния и ресурсов.
