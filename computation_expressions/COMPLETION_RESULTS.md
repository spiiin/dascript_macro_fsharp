# Завершение четырёх пунктов

| Пункт | Было до этого прохода | Доделано |
|---|---|---|
| State | state_modify/state_gets для трёх builders, обычные сценарии проверены | Запускаемый пример, исключения mapper/projection, пропуск после Error, повтор deferred после ошибки |
| Диагностика | Позиция and_bind была вписана в текст; оставался каскад | Одна целевая ошибка на реальной строке marker; отдельная автоматическая проверка позиции и отсутствия каскада |
| Подключение | Manifest и exporter отделяли поставку, исходники были плоскими | lib/examples/tests/support/benchmarks физически разделены; PUBLIC_API.md включён в экспорт; независимый smoke дополнительных модулей |
| Метрики | Allocation counters были готовы; компиляция CE/manual измерялась вместе | Шесть отдельных программ Result/State/List, парные checksums, раздельные compile/simulate и текстовые размеры, сырые samples и source hashes |

## Проверки

Полный run_computation.ps1 -Test: 179 проверок файлов, диагностические проверки,
отдельный экспорт с собственным builder и дополнительными публичными модулями,
три проверки раскрытия BindReturn/State/List. Подмножество JIT: 4 проверки прошли.
Хеши 230 развёрнутых .das-файлов совпали с проверенным деревом.
Из основной папки повторно прошли диагностические проверки, внешний экспорт
и test_state_operations_failures. Проверки исключений выполнялись в интерпретаторе;
известное ограничение JIT остаётся в [RELIABILITY.md](RELIABILITY.md).

Подробности: [State](STATE_OPERATIONS.md), [ошибки](DIAGNOSTICS.md),
[подключение](INTEGRATION.md), [публичные операции](PUBLIC_API.md),
[методика измерений](PERFORMANCE_METRICS.md).

## Измерения

Последовательный сеанс из основной папки, без параллельного прогона регрессии:
10000 операций × 5 runtime samples, 3 compile/simulate samples на каждую
независимую программу. Проверены checksums, остаточная память и все allocation
samples. Времена зависят от машины, включают старт процесса и simulate;
это не доказательство ускорения и не тестовый порог.

### Выделения основного heap на операцию

| Нагрузка | CE: число / байты | Ручной код: число / байты |
|---|---|---|
| result_mixed | 0 / 0 | 0 / 0 |
| state_loop | 0 / 0 | 0 / 0 |
| state_variable | 0 / 0 | 0 / 0 |
| list_product | 1 / 64 | 1 / 64 |
| sequence_protected | 4 / 264 | 4 / 264 |

Строковый heap измеряется отдельно в JSON/CSV; в этих нагрузках его дельты нулевые. Числа относятся к этим workloads, не ко всем CE.

### Компиляция и текстовое раскрытие

| Режим | Программа | CE, ms | Ручной код, ms | Текст CE, байт | Текст ручной, байт |
|---|---|---|---|---|---|
| interpreter | result | 966.73 | 83.67 | 6295 | 1641 |
| interpreter | state | 856.71 | 85.27 | 8257 | 628 |
| interpreter | list | 830.21 | 82.96 | 6687 | 1550 |
| jit | result | 11577.03 | 10906.52 | 6295 | 1641 |
| jit | state | 8439.58 | 10219.46 | 8257 | 628 |
| jit | list | 7500.18 | 6847.23 | 6687 | 1550 |

Размеры — entry-program -log, не полный AST импортированных модулей и не машинный
код. Ручные программы не импортируют CE, поэтому сравнение включает стоимость
подключения библиотеки. Фазы компилятора и разброс samples сохранены в логах/CSV.
После измерений исправлен расчёт median для чётного -Samples; опубликованные
сеансы используют 3 samples, их результаты от этого исправления не меняются.
